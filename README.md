# Парсер магазинов

Графическое приложение на PyQt6 для сбора названия, ссылки и цены товаров с российских маркетплейсов. Результаты сохраняются в локальную базу SQLite и отображаются в таблице, а также в двух диаграммах, которые можно сохранить как PNG.

## Возможности

- Поддержка площадок:
  - Wildberries;
  - Ozon;
  - Яндекс Маркет;
  - МегаМаркет;
  - Joom.
- Определение магазина по домену ссылки.
- Быстрый запрос к API Wildberries для ссылок на карточки товаров.
- Парсинг страниц через Camoufox, если быстрый способ недоступен.
- Извлечение данных из карточек товаров, JSON-LD, метатегов и ссылок выдачи.
- Сохранение до 20 товаров за один запрос.
- Автоматическая миграция старого поля `description` в поле `link`.
- Отдельная цветовая тема для каждой площадки.
- Диаграммы цен и распределения товаров по ценовым диапазонам.
- Экспорт диаграмм в формате PNG.
- Фильтрация товаров по выбранному магазину.

## Технологии

| Библиотека | Версия | Назначение |
| --- | ---: | --- |
| PyQt6 | 6.12.0 | Графический интерфейс и работа с SQLite |
| Matplotlib | 3.11.2 | Построение диаграмм |
| httpx | 0.28.1 | Асинхронные HTTP-запросы к API Wildberries |
| Camoufox | 0.5.8 | Браузерная загрузка и парсинг страниц |
| selectolax | 1.0.2 | Быстрый разбор HTML |

Остальные импортируемые модули (`asyncio`, `json`, `pathlib`, `re`, `sys` и `urllib.parse`) входят в стандартную библиотеку Python.

## Установка и запуск

Требуется Python 3 и созданное виртуальное окружение.

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Если браузер Camoufox ещё не загружен, выполните:

```bat
camoufox fetch
```

Запуск приложения:

```bat
python main.py
```

## Использование

1. Запустите `main.py`.
2. Выберите площадку кнопкой с логотипом.
3. Вставьте ссылку на товар, категорию или выдачу.
4. Нажмите **Поиск**.
5. Дождитесь появления товаров в таблице и диаграмм.
6. При необходимости сохраните диаграмму кнопкой **Скачать диаграмму №1** или **Скачать диаграмму №2**.

Для ссылки на один товар приложение сохраняет его название, исходную ссылку и цену. Для ссылки на выдачу сохраняются найденные карточки товаров с их ссылками.

## База данных

Основная таблица `goods` содержит поля:

- `id` — идентификатор записи;
- `name` — название товара;
- `link` — ссылка на товар;
- `price` — цена;
- `shop_id` — внешний ключ на таблицу магазинов `shops`.

При первом запуске приложение само создаёт таблицы и заполняет справочник магазинов. Если использовалась старая версия с полем `description`, при подключении оно автоматически будет переименовано в `link`.

## Важно

Страницы маркетплейсов могут менять HTML-разметку, поэтому отдельные селекторы в `config.py` иногда потребуется обновить. Работа парсера также зависит от доступности сайтов, интернет-соединения и актуальности браузера Camoufox.
